# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's advisory form:
<https://github.com/hellpuffyt/promptdiff/security/advisories/new>

Please do not open a public issue for a vulnerability.

In scope, for example: reading files outside the fixtures directory, any
network access or model call made by the shipped code, unsafe YAML or
schema handling, or a crafted fixture that hangs the tool.

## Supported versions

Only the latest release on the default branch receives fixes.
